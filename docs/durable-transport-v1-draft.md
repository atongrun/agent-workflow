# Native Durable transport v1

Generic PRIVATE wire supplied by the parent on 2026-10-07. This replaces the
previous provisional defaults; the filename is retained for existing links.
Published Pi Durable baseline is 1.0.4, source
`7c10bd4337495ee613f2224843ecdf349b80d1df`. Go implements transport and process
ownership; PRIVATE owns business schemas and native admission/delivery.

## Boundary

Go provides the existing Host HTTP listener, trusted credential-to-owner
mapping, bounded JSON, one private Unix socket and one long-lived operator worker
with an OS storage-owner lease. It has no execution ledger, scheduler, checkpoint,
attempt/session identity, mutation retry or agent recovery implementation.

PRIVATE implements Pi extensions/Skills and the existing catalog/CAS selection.
Its native Harness owns sessions, context, tools, submissions, progress, abort
and recovery. PRIVATE checks owner/native identity on lookup, list and cancel,
excludes editor children, freezes model selection and validates result references,
writer/editor label counts and fallback. Go treats business input/result as JSON.
Browser input cannot choose owner, fingerprint, provider/model configuration,
executable, environment or storage paths.

## Routes and trusted owner

Public routes retain `/v1/content`; Go translates to these worker routes:

| Public route | Private worker route |
| --- | --- |
| POST `/v1/content/submissions` | POST `/v1/submissions` |
| GET `/v1/content/requests/{requestId}` | GET `/v1/submissions/by-request/{requestId}?owner={trustedOwner}` |
| POST `/v1/content/requests/{requestId}/abort` | POST `/v1/submissions/by-request/{requestId}/cancel` |
| GET `/v1/content/conversations/{cid}/submissions/{sid}` | GET `/v1/submissions/{cid}/{sid}?owner={trustedOwner}` |
| POST `/v1/content/conversations/{cid}/submissions/{sid}/abort` | POST `/v1/submissions/{cid}/{sid}/cancel` |
| GET `/v1/content/submissions?limit=...&cursor=...` | GET `/v1/submissions?owner={trustedOwner}&limit=...&cursor=...` |
| Startup readiness | GET `/v1/health` |

Go authenticates first. Owner is `[A-Za-z0-9_-]{1,80}`; request IDs are lowercase
canonical UUIDv4. Native cid/sid are positive integers at most `9007199254740991`.
GET owner is in the generated query. Both cancel bodies are generated by Go as
`{"version":1,"owner":"owner_a"}`. Public abort accepts no body. Submit body is
`{version:1,owner,requestId,fingerprint,capability,payloadSchema,opaquePayload}`.
Worker POST Content-Type is `application/json`. Browser headers, owner query,
owner body and credentials are not forwarded; `X-AWF-Owner` is not a carrier.

Public submit accepts exactly
`{version:1,requestId,capability,payloadSchema,opaquePayload}`. Duplicate/unknown
fields, wrong tag spellings, invalid UTF-8 and isolated UTF-16 surrogates fail
closed. Public/native error shape is separately validated. There is no redirect,
idempotency-key forwarding or mutation retry. Lost ACK recovery is a read of the
original request; lookup does not submit, resolve a model or finish admission.

## Canonical fingerprint

Hash UTF-8 canonical JSON of `{capability,payloadSchema,opaquePayload}` before
PRIVATE fills business defaults. Version, owner and requestId are excluded.
All object keys sort recursively by JavaScript UTF-16 ordering, arrays preserve
order. Root bytes order is `capability,opaquePayload,payloadSchema`. Numbers and
strings use JSON.stringify scalar encoding: `1.0` normalizes to `1`, negative
zero to `0`, HTML is literal, U+2028/U+2029 are real UTF-8, and literal backslashes
remain escaped JSON backslashes. Reject unsafe integer numbers and nonfinite
numbers before sending. No blanket replacement of escaped Unicode substrings.

The supplied rewrite fixture SHA is
`e2e0a6c3f2eecdde0f105e99c5a24eb029c42dc1c54893ed86b5c7f22d96f03b`;
its source.version `1.0` normalizes to `1`. Go tests check those exact bytes.
A deterministic 512-number corpus also checks Go against the available Node
JSON.stringify runtime; this is scalar compatibility, not native SDK acceptance.

PRIVATE supplied authoritative current TS probes (Node 22.22.2) to freeze the
remaining byte details. The saved generate fixture has one literal backslash:
its opaque JSON is 128 UTF-8 bytes and its canonical hash input is 208 bytes,
SHA `f937a1e281bff96e82ef02a5c873587e6a5d6781010a85b9f07d6396a7e4afe2`.
Tests retain the exact base64 byte vectors instead of retranscribing escapes.
Numeric-like keys sort textually: `{"2":2,"10":10}` becomes `{"10":10,"2":2}`.
Root is depth zero. Only object/array containers at depth at least 32 are
rejected: 31 and 32 nested containers ending in a scalar are accepted; 33 are
rejected. A scalar leaf at depth 32 is valid. The complete HTTP envelope counts
as a root container for frame validation. There are no unresolved byte-reference
questions; actual cross-implementation execution remains an acceptance gate.

## Receipts, history and cancellation

Receipt has no owner echo. Receipt and every list item have `version:1`,
requestId, positive conversationId, status and required boolean abortRequested.
`admission_pending` is a successful receipt with real cid and omitted sid;
explicit sid `0`/`null`/positive is invalid. Other statuses `queued`, `placed`,
`done`, `unanswered` require a real positive safe sid. Reason is an optional
native string; arbitrary reasons become fixed public `unanswered`, while
released safe codes pass through. Detail is optional and accepts only
`dispatch_requires_verification`, `request_budget_exhausted`, `stage_failed`;
Go drops detail in its public projection. Other unknown fields remain rejected.

Optional result is bounded opaque JSON only when native status is `done` and
abortRequested is false. Pending/unanswered/cancelled receipts cannot contain
result, including JSON null. PRIVATE validates typed Doc delivery and reference
ownership. A late cancel may legally return completed done/false with cached
result: Go validates it and then omits result from public abort, preserving the
completed receipt instead of generating unavailable or new work.

List is `{version:1,items:[receipt-without-result...],nextCursor:string|null}`.
It has no owner echo, and items still contain version and optional reason/detail.
Go bounds count and validates fields, without rebuilding history or imposing a
second root/child execution index. PRIVATE owns root identity/order/owner binding,
cursor integrity and the first-batch upper boundary across cold reopen. Its
native scan is at most 128 steps. Empty items with non-null continuation are
valid; Go forwards one page without another read. Cursor is opaque and retained,
not decoded/reconstructed; the nullable nextCursor field is required.

Worker errors are `{version:1,error:"invalid_input"|"not_found"|
"request_conflict"|"unavailable"}` with HTTP 400/404/409/503. Public error
projection stays `{version:1,error:{code}}`, including Go's own authentication,
method and body-size errors. Admission pending is not a 409 error. Submit success
is exactly 202; lookup/list/cancel success is 200. Unknown codes, wrong versions,
IDs, shape, bounds or redirects become generic unavailable, without private
messages/stderr. Public responses use JSON and `Cache-Control: no-store`.

## Bounds

| Value | Maximum UTF-8 bytes/count |
| --- | ---: |
| Complete public and worker request body | 131072 |
| Canonically encoded opaque input | 65536 |
| Opaque result JSON | 65536 |
| Opaque cursor | 2048 |
| List default / maximum limit | 20 / 50 |
| Native per-page scan | 128 steps |

Go retains a 512 KiB aggregate worker response read ceiling. Opaque input/result
limits are independent. Cursor currently comes from PRIVATE as ASCII; Go
retains valid UTF-8 strings without control characters, including an empty
string if present. Root-zero container depth at least 32 is rejected as specified above. Public/worker bodies cannot evade their final byte
limit through additional trusted fields or string encoding expansion.

## Process and storage ownership

Use UDS only in a Go-owned temporary 0700 runtime directory, socket 0600.
Persistent native SQLite remains in operator-provisioned 0700 storage. Go takes
`flock(LOCK_EX|LOCK_NB)` on singly linked service-owned 0600
`<storage>/.awf-owner.lock` and passes the same open-file description as FD3
through ExtraFiles. Reserved environment includes `AWF_DURABLE_PROTOCOL=1`,
`AWF_DURABLE_OWNER_FD=3`, `AWF_DURABLE_STORAGE_DIR`, `AWF_DURABLE_SOCKET`;
`PI_CODING_AGENT_DIR` isolates the service Pi-agent directory. Operator args
provide PRIVATE's `--bootstrap=<absolute trusted bootstrap path>`; its bootstrap
checks FD dev/inode/nlink/owner/mode against that lock before factory/native open.

PRIVATE does not acquire a second lock, unlink/replace/unlock the inode, or pass
FD3 to tools. Go closes only its own copy after confirmed shutdown, never
LOCK_UN. Unknown join retains the descriptor/runtime until owned worker exit
and join are established. Production replacement additionally requires verified
systemd control-group cleanup of detached native tools. The published Durable
README lacks cross-process locking; this is the remaining Go machine/process gap.

Health is `{version:1,durableVersion:"1.0.4",ready:true}` only after native open,
recovery and live HTTP admission. Local Go fixtures do not prove native storage,
PRIVATE ownership/delivery, installed command lifecycle, systemd or Ubuntu
service acceptance. No public/private CI or real model invocation is run here.
