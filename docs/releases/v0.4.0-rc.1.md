## Product change

This candidate closes the bounded committed-Plan product journey:

```text
awf init
  -> exact local managed RoleBindings Ready

authorized Agent: awf plan start --plan <tracked-plan> --one-card|--milestone
  -> existing Fast/Deep
  -> fresh Pi TaskCard
  -> existing Coder / trusted PR / exact-head Reviewer / bounded rework
  -> fresh Pi terminal Decision / exact CI / trusted merge
  -> CompletedCardFact
  -> fresh main + next Pi, or MILESTONE_COMPLETE

awf status   # passive
awf stop     # safe aggregate stop
```

Agent Bus remains transport-only and independently pinned to formal `v0.3.1`. Runtime v2 Store is
not the production default. Existing compatibility/support commands remain available.
